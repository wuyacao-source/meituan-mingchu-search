# 美团外卖 · 明厨亮灶搜索 🔍

输入中国城市名称，搜索该城市在美团 APP 上的外卖商家，并自动按「明厨亮灶」标签进行分类统计。

## 功能

- 🔍 城市搜索 — 输入任意中国城市名称，一键搜索外卖商家
- 🟢 明厨亮灶分类 — 自动识别并筛选具有「明厨亮灶」标签的商家
- 📊 数据统计 — 展示总数、明厨亮灶数、占比等关键指标
- 📋 商家详情 — 评分、月销量、配送时间、配送费、标签信息
- 🎨 美团风格 UI — 黄色主题，移动端适配

## 快速开始

```bash
# 1. 安装依赖
npm install

# 2. 启动服务器
npm start

# 3. 打开浏览器访问
open http://localhost:3456
```

## 技术架构

```
meituan-search/
├── server.js          # Express 后端服务 (端口 3456)
├── scraper.js         # Puppeteer 数据获取引擎
├── public/
│   └── index.html     # 前端界面
└── package.json
```

### 数据获取策略（3层降级）

1. **API 拦截** — 拦截美团 H5 页面内 `shopList` / `rcmd` 等 API 响应，解析 JSON 获取结构化商家数据
2. **DOM 提取** — 遍历渲染后的页面文本节点，通过「月售」锚点精准定位商家卡片
3. **演示数据** — 反爬保护触发时，生成符合真实市场比例的模拟数据

### 数据来源

美团外卖 H5 网页版 (`waimai.meituan.com`) 公开可访问的商家列表数据。

## 「明厨亮灶」是什么？

「明厨亮灶」是食品安全的重要标识，指餐饮商家将厨房实时视频公开，让顾客可以看到食品制作全过程，保障食品安全。

## 依赖

- Node.js >= 18
- Chrome 浏览器（Puppeteer 使用）

## 许可

仅用于食品安全信息查询与研究。
